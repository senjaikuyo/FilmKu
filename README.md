# Filmku

Aplikasi Flutter sederhana untuk mencatat film dan mengelola daftar tontonan.

## Fitur

- Katalog film dengan pencarian judul.
- Detail film dan ulasan.
- Watchlist dengan penghitung dan opsi hapus.
- Tema antarmuka hitam-putih.

## Menjalankan aplikasi

```sh
flutter pub get
flutter run
```

## Pemeriksaan

```sh
flutter analyze
flutter test
```
